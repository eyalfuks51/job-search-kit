# ערכת חיפוש עבודה עם Claude

עוזר שמחפש משרות ישירות באתרי הקריירה של מעסיקים, קורא את תיאור המשרה המלא מול קורות החיים שלך, ומציג רשימה קצרה עם הסבר: למה מתאים, מה חסר, וקישור להגשה.
הוא זוכר מה כבר ראית ומה החלטת, כך שבפעם הבאה תראי רק משרות חדשות.
**הוא אף פעם לא מגיש מועמדות ולא שולח הודעות בשמך.**

## מה צריך (פעם אחת)

1. מנוי Claude בתשלום (Pro ומעלה). התוכנית החינמית לא כוללת את Claude Code.
2. להתקין את אפליקציית Claude למחשב מ-[claude.ai/download](https://claude.ai/download) ולהתחבר.
3. להוריד את הערכה: בראש העמוד הזה ללחוץ על הכפתור הירוק **Code** ואז על **Download ZIP**.
4. לחלץ את הקובץ (ב-Windows: קליק ימני ← Extract All. ב-Mac: לחיצה כפולה על הקובץ). תיווצר תיקייה בשם `job-search-kit-main`. כדאי להעביר אותו למקום קבוע, למשל Documents, ואפשר לשנות לו את השם.

## להתחיל

1. לפתוח את אפליקציית Claude, לעבור ללשונית **Code** ולבחור את התיקייה `job-search-kit-main`. **חשוב:** לבחור את התיקייה שבתוכה נמצאים ישירות הקבצים `README.md` ו-`CLAUDE.md`. ב-Windows לפעמים יש תיקייה באותו שם בתוך תיקייה, ואז צריך לבחור את הפנימית.
2. אם מופיעה שאלה אם לסמוך על התיקייה, לאשר.
3. להדביק את ההודעה הזו ולשלוח:

```
שלום, אני רוצה להתחיל לחפש עבודה. תקרא את ההוראות של הערכה ותדריך אותי צעד אחר צעד. אני לא טכנית.
```

Claude ישאל על קורות החיים ועל מה שאת מחפשת, יכין את החיפוש ויראה לך את המשרות הראשונות. בפעם הראשונה הוא עשוי לבקש אישור להתקין Python (תוכנה חינמית שהערכה צריכה). זה קורה פעם אחת.

## בפעמים הבאות

לפתוח שיחה חדשה באותה תיקייה ולכתוב:

| מה רוצים | מה לכתוב |
|---|---|
| משרות חדשות | `מה חדש?` |
| מצאת משרה בעצמך | `מצאתי משרה:` ואחריו הקישור או הטקסט של המשרה |
| להגיב על הרשימה | למשל: `2 ו-5 מעניינות, 3 לא כי זה מכירות` |
| לראות מה שמרת או הגשת | `מה שמרתי?` |
| לשנות את מה שמחפשים | למשל: `אני רוצה להוסיף גם ניהול פרויקטים` |
| משהו לא עובד | `משהו לא עובד, תבדוק` |

## מה הערכה לא מכסה

היא קוראת לוחות משרות של מעסיקים שמשתמשים במערכות גיוס נפוצות (בעיקר חברות הייטק).
היא **לא** מכסה את LinkedIn, קבוצות פייסבוק, AllJobs, דרושים, חברות השמה ואתרים רבים אחרים.
Claude יגיד לך מה לא נבדק ויציע התראות משרות שכדאי להגדיר. משרה שמגיעה משם אפשר פשוט להדביק לו.

## פרטיות

- כל המידע שלך (קורות חיים, העדפות, משרות) נשמר בתיקייה `me` במחשב שלך בלבד.
- קורות החיים והשיחה נשלחים ל-Claude כדי לנתח את המשרות.
- לא להעלות את התיקייה `me` לשום מקום. אם תיקיית Documents מסונכרנת ל-OneDrive או ל-Google Drive, גם היא תסונכרן.

**English:** a Claude Code-operated job search kit. Download, open the folder in the Claude desktop app (Code tab) and say "I want to start looking for a job". `CLAUDE.md` is the operating manual. Python standard library only. Personal data stays in the git-ignored `me/` folder. Tested on Windows; macOS support is written but has not been tested on a real Mac.
